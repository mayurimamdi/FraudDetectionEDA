# Fraud Detection – Exploratory Data Analysis

## 📌 Project Overview
This project performs exploratory data analysis (EDA) on a fraud detection dataset
to identify patterns, anomalies, and insights related to fraudulent transactions.

## 🔧 Tools & Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## 📊 Key Analysis
- Data cleaning and preprocessing
- Missing value analysis
- Distribution of features
- Outlier detection
- Fraud vs non-fraud comparison

## 🚀 How to Run
Open the notebook using:
- Google Colab, or
- Jupyter Notebook

## 📁 Dataset
Dataset used is not included due to size/privacy reasons.
